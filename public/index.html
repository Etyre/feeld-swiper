Settings

Start batch browses Discover for a random session length. New profiles are judged and browsed past without a like or pass; you decide in the To review tab, and the next batch does your likes, pings and passes when those profiles come round again.

Veg*n score

P(veg*n): how likely they are vegan, vegetarian, or otherwise not subsidizing factory farming. A Bayesian estimate: it starts from the prior and updates on the bio, tags and photos.

Base rate of veg*n profiles in your pool. Needed likelihood ratio for 50%: ×

Personal fit score

Fit: how good a match they'd be for you, judged against your own description below, separately from diet. The model's raw score is turned into a percentile of everyone scored so far: 99 means a better fit than 99% of the pool, so the bars below are cuts on the ranking and the top of the pool always clears them.

The two scores are independent routes: a profile is a ping if it clears either ping bar, a like if it clears either like bar, otherwise a pass. In the ranked list, profiles that clear both bars come first. Flag clear good fits on cards with ⭐; they're shown to the model as reference cases.

Pings

A ping is Feeld's super like: a like that carries a message, sent before you match. For each recommended ping the drafting model writes three openers in your voice, drawing on your date-me page and the notes above; you edit them in the To review tab. You can also ping any profile from its card. When Feeld is out of pings, the app sends a regular like instead.

Judging

First it judges on the profile text and the first screen. Below this P(veg*n), and with no promising fit, it decides on that alone. Otherwise it sends every screen and re-scores with the full set. At 100% every profile is judged on text and first screen only; at 0% every profile gets the full look.

Batches

Each Start runs one batch, like a person browsing for a while, then stops. Also stops when Feeld runs out of profiles or likes, or when it keeps showing profiles you've already seen.

Behavior

How to move past a profile without liking or passing. Test it first with Next (no vote) on the phone panel and watch the phone: if a heart or X flashes, or a match screen appears, that gesture is a vote on your build; pick another. A batch stops itself if the gesture ever produces a match screen.

Screenshots of the profile, evenly spaced from top to bottom. Each costs roughly a thousand input tokens.

The Agent SDK runs the Claude Code harness as a subprocess with every tool switched off: one prompt in, one JSON object out. Token counts come from the harness; its cost estimate is logged per profile.

Device

Booted in the background when nothing is connected. Create it once with npm run emulator.

A real Android phone over USB with debugging on works too; the phone panel drives it the same way.

Feeld's Discover feed follows the phone's GPS. The emulator is pointed here whenever it connects or you save; a real phone uses its own location.
